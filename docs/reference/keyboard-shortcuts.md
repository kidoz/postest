# Keyboard shortcuts

On macOS use **Cmd**; on Linux and Windows use **Ctrl**.

| Shortcut | Action |
|----------|--------|
| `Cmd/Ctrl + Enter` | Send the active request |
| `Cmd/Ctrl + T` | Open a new tab |
| `Cmd/Ctrl + N` | Open a new tab (same action as `Cmd/Ctrl + T`) |
| `Cmd/Ctrl + W` | Close the active tab |

If a tab has unsaved edits, closing it asks for confirmation. Tabs without changes close immediately.

`Cmd/Ctrl + Enter` also works while the URL field is focused.

## Split panes

When a pane divider has keyboard focus:

| Key | Action |
|-----|--------|
| Arrow keys | Move the divider |
| `Home` | Move to the minimum |
| `End` | Move to the maximum |

## Mouse

- Click a collection item to open it in a new tab.
- Drag a request or folder row onto a folder header to move it inside.
- Drag onto the collection header to move it to the collection root.
- Drag a splitter to resize panes.
