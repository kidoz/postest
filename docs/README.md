# Postest documentation

Postest is a desktop REST API client for Linux, macOS, and Windows, built with Kotlin and Compose Multiplatform.

This documentation follows the [Diátaxis](https://diataxis.fr/) approach. Content is split by what you need:

| Mode | Use it when you want to... | Start here |
|------|----------------------------|------------|
| **Tutorials** | Learn by doing, from a clean start | [Send your first request](tutorials/first-request.md) |
| **How-to guides** | Accomplish a specific task | [Import and export](how-to/import-and-export.md) |
| **Reference** | Look up exact facts and limits | [Keyboard shortcuts](reference/keyboard-shortcuts.md) |
| **Explanation** | Understand how and why it works | [Architecture](explanation/architecture.md) |
